# Project 04-05：频率域相关

本目录独立存放成员 C 的 Project 04-05 工作，完成后将报告内容并入小组总报告。

```text
project_04_05/
├── input/       原始输入图像与模板图像
├── results/     运行生成的结果图和数据
├── src/         本项目代码
└── report.md    独立实验报告草稿
```

`input/4.41a.jpg` 为 256×256 的原图，`input/4.41b.png` 为 49×44 的模板截图。程序保留原文件，运行时按半开像素区域 `(6, 1, 44, 43)` 将模板裁成 38×42，再将两图补零至 298×298。

安装 `requirements.txt` 中的依赖后，在本目录运行：

```bash
python src/project_04_05.py
```

运行后会弹出原图、裁剪模板、相关图和峰值标注图的四图窗口；关闭窗口后程序结束。只想保存结果而不弹窗时使用 `python src/project_04_05.py --no-show`。

程序将裁剪后的模板、两张 298×298 补零延拓图、相关函数显示图、原图上的峰值标注图、原始相关数组和峰值数据写入 `results/`。补零延拓图分别为 `04_05_image_padded.png` 和 `04_05_template_padded.png`，仅保存到文件，不加入运行后的四图窗口。报告中的 `(x,y)` 使用从零开始的坐标，`x` 是列、`y` 是行，代表模板左上角在原图中的位置。原始相关值保存在 `.npy` 文件中；`04_05_correlation_display.png` 按最大值线性映射，`04_05_correlation_log_display.png` 使用对数映射以便观察弱响应。不要用 PNG 像素值替代原始相关值。

每次运行还会对模板完全位于原图内的所有位置执行空间域逐像素乘积求和，与 FFT 相关结果逐点比较。校验峰值和最大绝对误差同时输出到终端，并记录在 `results/04_05_peak.json` 中。
